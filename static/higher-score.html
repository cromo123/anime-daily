Category guide

Higher Score

Which of the two displayed anime entries has the higher MyAnimeList user score? The larger stored score wins. Both values are shown after you choose.

A season has its own score

MAL can list a first season, sequel, movie, and special separately. AniMoredle uses the score of the exact entry shown, not a franchise average and not a combined score across seasons. Recognizing a title is useful, but a familiar series name does not guarantee that every release has the same rating.

What the number does and does not mean

The score is a MAL community rating recorded in AniMoredle’s catalog. It is not a score assigned by AniMoredle, an editorial agent, or the player. It also is not the same as popularity: a smaller audience can rate an entry highly, while a much more widely listed title can have a lower score.

Very close matchups can be surprising. The game checks the underlying stored values, so it does not accept a factual tie. It shows the authoritative stored score at the end of the reveal, even if an animated value briefly looks equal while counting up.

Why MAL may show a different score later

Community ratings change. AniMoredle uses imported data rather than a live request at answer time, so later MAL votes or catalog updates may create differences. After answering, the reference link lets you inspect the actual entry.
