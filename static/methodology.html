The facts behind the game

Data and Methodology

AniMoredle is an independent game using structured anime data from the MyAnimeList website ↗ and its official API. It is not an official MyAnimeList product.

A stored catalog, rather than live lookups

Anime scores, membership counts, episode counts, release dates, media types, and cover references are imported into a local catalog. Gameplay reads that catalog; it does not request fresh MAL data after each choice. Numbers may therefore differ from the MAL page you visit later.

Catalog refreshes can update values, but there is no guaranteed live refresh interval. User scores and membership counts change, and ongoing series may gain episodes or corrected release information. Historical recap values and correct choices reflect the catalog currently stored, rather than an immutable snapshot of MAL on that historical date. Community percentages reflect the correctness recorded for original official answers; those statistics are not re-scored when the catalog changes.

Selection and factual validation have different jobs

Candidate lineups favor recognizable anime, with room for less familiar picks. Recent use in the same category and recent exact matchups are checked to keep days varied. A challenge uses 24 distinct MAL entries across four rounds.

Automated editorial agents can suggest a balance of familiarity, difficulty, and release eras, then choose a lineup from valid candidates. They do not supply numerical answers. Python compares the structured values and requires both values to be present and unequal for every adjacent matchup. A tie or missing comparison value cannot be an accepted question.

Entries and connected series

Score, popularity, and recency belong to the particular MAL entry shown. Different seasons can have different values.

More Episodes is the exception. It uses a connected mainline series total while showing a verified first-released episodic representative. Only prequel/sequel relationships define that connection; title similarity does not.

Limitations and corrections

MAL’s relationships and missing metadata affect what can be established reliably. Incomplete or cyclic representative graphs are excluded from More Episodes selection. Unknown episode counts are not invented, and series totals can lag new releases. This is a factual comparison game built on a catalog, not a judgment of an anime’s artistic quality.

If you find a mismatch, report the entry, category, challenge date, and what looks wrong. A link to the relevant MAL entry helps identify the issue without relying on similarly named seasons.
